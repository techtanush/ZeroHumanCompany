## Milestone acceptance rule

A milestone is done only when:

1. The artifact exists and validates.
2. The Boardroom renders it.
3. At least one event trace proves how it was produced.
4. The fallback path is visible or documented in demo seed.
5. The next milestone can consume it without manual editing.

## Assumptions & open questions

- **MVP:** Optimize for a coherent four-minute proof, not broad production coverage.
- **POST-MVP:** Roadmap dates depend on sponsor API access and legal review.
